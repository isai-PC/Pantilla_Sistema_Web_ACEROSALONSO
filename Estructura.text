acerosalonso/                  ← Raíz del proyecto
├── public/                   ← Archivos que se servirán directamente
│   ├── assets/               ← Recursos públicos
│   │   ├── css/              ← CSS compilado (Tailwind)
│   │   │   └── output.css
│   │   ├── js/               ← JS compilado
│   │   │   └── bundle.js
│   │   ├── images/           ← Imágenes
│   │   └── fonts/            ← Tipografías
│   ├── index.html            ← Página principal
│   └── (Otras páginas .html) ← por ejemplo, servicios.html
│
├── src/                      ← Código fuente editable
│   ├── assets/               ← Recursos sin compilar
│   │   ├── images/
│   │   └── fonts/
│   ├── css/                  ← Tailwind input
│   │   └── input.css
│   ├── js/                   ← Tu JavaScript
│   │   └── main.js
│   └── index.html        ← Copia editable de la vista
│
├── node_modules/             ← Paquetes NPM
├── .gitignore
├── tailwind.config.js        ← Configuración de Tailwind CSS
├── postcss.config.js         ← Configuración PostCSS
├── package.json              ← Dependencias y scripts
└── README.md
 
 

Esto se ejecuta en la termial al final, se tiene que tomar la carpeta de public
lo que se sube: public/
   index.html
   pages/
   assets/
       css/output.css
       js/

Ejecutar sto antes de subir: npx tailwindcss -i ./src/css/input.css -o ./public/assets/css/output.css --minify

./src/css/input.css -o
 ./public/assets/css/output.css --watch


 ejecutar esto cuando se este desarrollando:
 npm run watch:css
 ejecutar esto para subir:
 npm run build:css
